# One at a time — BRAND v2

**The one rule: one sentence, one word, one button.** If a screen shows more, cut it.
Full spec: [DESIGN.md](DESIGN.md). v1 ("I Missed That": walnut, linen, mascot, illustrated icons) is retired.

## Palette (single theme, flat)
| token | hex | use |
|---|---|---|
| cream | `#F4EEE2` | every page background |
| ink | `#17130F` | text (15:1 on cream) |
| ink-2 | `#5E554B` | names, state word, footnotes |

Speaker dots keep their colors. No gradients, shadows, textures, icons, mascot, cards, badges.

## Type
- **Fraunces** italic, SOFT 100, opsz 144, wght 500: sentences, the lamp word, the wordmark (plain text *One at a time*).
- **Nunito** 500/700: names, buttons, paragraphs. Body ≥17px.
- **Space Mono** 12px caps, tracking .14em: labels only.

## Motion
160–200 ms opacity/translate; page color changes 200 ms; reduced motion = instant.
